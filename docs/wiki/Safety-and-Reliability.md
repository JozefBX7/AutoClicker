# Reliability

AutoClicker stops active input when you stop or close it.

- Use the global hotkey to start or stop from anywhere.
- Only one copy can run at a time.
- Closing the app stops the current run.
- The optional **Restart after an unexpected crash** setting can reopen the app after a crash. It does not restart after a normal close or forced termination.

AutoClicker uses efficient Windows input and waits, but very short intervals can vary slightly when the PC is busy. Keep a clear stop hotkey and use a sensible interval for the app you are controlling.
