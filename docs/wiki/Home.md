# AutoClicker

AutoClicker is a small Windows tool for repeating mouse clicks, key presses, and custom sequences. It has a global hotkey, saved settings, and optional OpenRGB lighting.

Use automated input only where it is permitted.

## At a glance

- Left, middle, and right mouse input; single or double click.
- Space, Enter, or any picked keyboard key.
- Repeat until stopped or for a chosen number of runs.
- Current cursor position or fixed coordinates.
- Custom sequences with click, key, and delay events.
- Saved sequence presets and backups.
- Configurable hotkey, pin-to-top, dark/light themes, and compact view.
- Optional OpenRGB hotkey lighting while active.
