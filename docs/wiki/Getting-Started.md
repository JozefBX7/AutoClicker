# Getting started

## Choose an install type

Download the current release from the repository’s **Releases** page.

### Installer (recommended)

Run `AutoClicker-Setup-x64.exe`. It installs normally, includes an uninstaller, and can create a desktop shortcut. Your settings stay in place if you reinstall.

### Portable

Extract `AutoClicker-Portable-x64.zip` anywhere and run `AutoClicker.exe`. No installation is required. Keep the `Data` folder with the app when moving or updating it.

## First run

1. Pick an interval. The default is **100 ms**.
2. Choose an action, such as **Left click**, **Space**, or **Pick a key**.
3. Choose whether to repeat until stopped or a set number of times.
4. Press **Start**, or use the global hotkey shown in the title bar (F6 by default).
5. Stop with **Stop** or the same hotkey.

Use the pin icon to keep the app above other windows. The theme icon switches light and dark mode; the centre bar hides or shows the settings area.

Use **Set as default** to remember your current choices. **Settings → Reset to defaults** restores the original setup.
