# Updates

AutoClicker never checks for updates by itself.

Open **Settings → Updates** and choose **Check GitHub Releases** whenever you want to check.

- **Installed copies:** choose **Download & install** to use the normal installer.
- **Portable copies:** the matching ZIP opens in your browser. Close AutoClicker, extract it over the portable folder, and keep the `Data` folder.

If no release is available, the app lets you know clearly.
