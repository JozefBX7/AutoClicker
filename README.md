# AutoClicker

A compact Windows auto clicker inspired by OP Auto Clicker. It offers configurable intervals, left/right/middle and single/double clicks, fixed or current cursor positions, repeat controls, and a global F6 start/stop hotkey.

## Run

```powershell
dotnet run --project C:\repos\AutoClicker\AutoClicker.csproj
```

Use only where automated input is permitted. Press **F6** at any time to stop clicking.

## Test

```powershell
dotnet test C:\repos\AutoClicker\AutoClicker.Tests\AutoClicker.Tests.csproj
```
